# فرهنگی (Farhangi)

اپلیکیشن فرهنگی فارسی — پلتفرم محتوای فرهنگی برای پرسنل نظامی، خانواده‌ها و عموم مردم.

> این اپ **هیچ** محتوای نظامی، طبقه‌بندی‌شده یا اتوماسیون سازمانی ندارد. همه‌چیز محتوای فرهنگی عمومی است.

## استک

- Android Native · Kotlin · Jetpack Compose
- Material Design 3 · RTL · Vazirmatn
- MVVM · Clean Architecture · Repository · Feature-first
- Hilt (DI) · Navigation 3
- Supabase (بک‌اند موقت، پشت interface — قابل مهاجرت به VPS خصوصی)
